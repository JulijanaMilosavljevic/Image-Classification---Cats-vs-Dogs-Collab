# 🐱🐶 Cat vs Dog Classifier

## 📌 Project Description
This project is a simple Computer Vision model that classifies images into two categories: cats and dogs.  
The model is built using **PyTorch**, trained on a subset of the **CIFAR-10** dataset, and uses a **Convolutional Neural Network (CNN)**.  
For the frontend, **Gradio** is used, which allows image upload and prediction directly from the browser.

---

## ⚙️ Technologies
- Python 3.9+
- PyTorch
- Torchvision
- Gradio
